# 主题改动先征得用户同意

制作 UI 时默认只用项目已有的 theme 与 `theme_type_variation`。以下操作会改变界面皮肤，必须**先向用户说明用途并征得明确同意**，不得自行决定：

- 使用或修改任何 `theme_override*`
- 创建新的 `Theme`
- 创建新的 `theme_type_variation`
- 修改现有的 `theme_type_variation`

用户同意后再动手，并在交付说明里写明改了哪一项、为什么。用户不同意时，改用容器、布局与已有变体表达，或请用户让美术统一改主题。

判据：diff 中出现上述任一主题改动时，交付说明里能看到对应的用户同意记录。
