# 按功能分目录，不按资产类型分

## 约定

目录按功能划分。不要建 `scripts/`、`tscns/`、`assets/` 这类按类型切开的目录。Godot 里脚本、场景、贴图、音频常常绑在同一个功能上，而且一个 `.tscn` 经常对应一份只给它用的脚本。

某个 `.tscn`，以及**只有它会引用**的资源，放进同一个目录。资源包括但不限于 `.gd`、子 `.tscn`、音乐、图片。

## 第二次被引用时

新建的东西用到了这份资源，就把该资源从原来那个 `.tscn` 的目录里拿出来，放到双方都能引用的共同上层目录。不要继续留在先用它的那个场景私有目录里。

共同上层里东西已经很多时，再在那里开一个公共资产目录，把这些被多处引用的资源放进去。这个目录只收该层下跨功能共用的资源，不是按脚本、场景、图片把整个项目切开。
